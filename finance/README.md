# 💰 ميزانيتي | MIZANIYATI — المستشار المالي الشخصي

برنامج إدارة مالية ومستشار مالي شخصي، يعمل **على الهاتف والكمبيوتر** مع **مزامنة مشفّرة**
بين أجهزتك عبر **مستودع GitHub خاص بك أنت** — لا يراك أحد، وأنت وحدك من يملك المفاتيح.

> 🔐 **خاص ومحمي**: خزنة مشفّرة بـ **AES-256-GCM**، والمفتاح مشتق من رمزك السري عبر
> **PBKDF2 (250,000 جولة)**. لا خادم، لا حسابات، لا تتبّع — البيانات تبقى لك.

---

## 🚀 التشغيل

### على الكمبيوتر
1. افتح `finance/index.html` مباشرة في **Chrome / Edge** — يعمل فوراً.
2. أو شغّل خادماً محلياً: `node finance/tools/serve.js` ثم افتح `http://localhost:8099/`.

### على الهاتف
- افتح الرابط المنشور في المتصفح ← قائمة المتصفح ← **«تثبيت التطبيق» / «Add to Home Screen»**
  ← يظهر أيقونة ميزانيتي ويعمل كتطبيق مستقل (بدون شريط المتصفح) **وبدون إنترنت بعد أول زيارة**.

### النشر (GitHub Pages)
المجلد `finance/` يُنشر تلقائياً مع المستودع:
`https://hdm8097-sketch.github.io/mycoach/finance/`

## ☁️ المزامنة بين الهاتف والكمبيوتر (مشفّرة)

المزامنة تتم عبر **مستودع GitHub خاص** تملكه أنت. المحتوى المُرفع **مشفّر** —
حتى لو اطّلع أحد على المستودع لا يرى شيئاً.

### الإعداد (مرة واحدة على كل جهاز)
1. أنشئ **رمز وصول (Personal Access Token)**:
   - افتح <https://github.com/settings/tokens> ← **Generate new token (classic)**
   - امنحه النطاق **`repo`** (أو Fine-grained: `Contents: Read and write` على مستودع واحد) — واحفظه.
2. افتح ميزانيتي ← ⚙️ الإعدادات ← ☁️ المزامنة:
   - **اسم المستخدم في GitHub** + **اسم المستودع** (أو اضغط **«إنشاء مستودع خاص تلقائياً»**).
   - **الرمز السري (PAT)** ← حفظ ← **«اختبار الاتصال»** ← **«تفعيل المزامنة»**.
3. اضغط **«مزامنة الآن»** — تُرفع خزنتك المشفّرة إلى المستودع.

### على جهازك الآخر
1. افتح نفس الرابط (`…/mycoach/finance/`).
2. أنشئ خزنة جديدة **بالرمز السري نفسه** (أو استخدم «نسيت الرمز؟» برمز الطوارئ).
3. ⚙️ الإعدادات ← ☁️ المزامنة ← أدخل نفس بيانات المستودع والرمز ← فعّل ← **«مزامنة الآن»**.

> عند وجود نسختين مختلفتين تظهر نافذة تعارض تطلب منك اختيار: **جلب النسخة السحابية**
> أو **رفع نسختي المحلية** — أنت من يقرر، ولا يُحذف شيء تلقائياً.

### المزامنة التلقائية
- تعمل كل دقيقة أثناء فتح التطبيق، وبعد كل إضافة/تعديل.
- المزامنة الصامتة لا ترفع بيانات غير مشفرة إطلاقاً.

## 🔐 الأمان والخصوصية

- **التشفير**: AES-256-GCM للمحتوى، PBKDF2-SHA256 (250k جولة) لاشتقاق المفتاح من الرمز.
- **رمز الطوارئ** `MZ-XXXX-XXXX-XXXX` يُعرض **مرة واحدة** عند إنشاء الخزنة —
  حفظه في مكان آمن؛ هو الطريقة الوحيدة لاستعادة الوصول لرمزك السري.
- **القفل التلقائي** بعد خمول (5/15/30/60 دقيقة أو أبداً) + زر قفل فوري.
- **إيقاف 30 ثانية** بعد 3 محاولات خاطئة.
- الرمز السري يُخزَّن **كملف مشفَّر في متصفحك فقط** — لا يُرسل لأي خادم.
- **ملاحظة صريحة**: من يملك جهازك ويستطيع فتح أدوات المطوّر يستطيع قراءة تخزين
  المتصفح؛ لذا أبقِ جهازك مقفولاً، واحتفظ بنسخة احتياطية ورمز الطوارئ في مكان آمن.

### النسخ الاحتياطي
⚙️ الإعدادات ← 💾 النسخ الاحتياطي:
- **تصدير JSON** (يحتوي بياناتك — احفظه في مكان آمن) — يمكن استيراده على أي جهاز.
- زر **«مسح كل البيانات»** في منطقة الخطر (يتطلب كتابة كلمة التأكيد).

## 🌐 اللغات والثيمات

- **العربية (RTL)** والإنجليزية (LTR) — زر التبديل أعلى الشاشة أو من الإعدادات.
- **4 ثيمات**: 🌙 دكن · ☀️ فاتح · 🌊 محيطي · 👑 ملكي — تُحفظ تلقائياً.
- الافتراضي: عربي + دكن + عملة الريال اليمني (تُغيَّر من الإعدادات — 21 عملة متاحة).

## 📱 ملاحظات

- يعمل بدون إنترنت بعد أول زيارة (PWA) — لكن **المزامنة تحتاج إنترنت**.
- المزامنة تحتاج **HTTPS** (GitHub Pages أو localhost) — Web Crypto لا يعمل على `file://` في بعض المتصفحات.
- جميع البيانات تُخزَّن في `localStorage` مشفّرة داخل ملف واحد `mizan.vault`.
